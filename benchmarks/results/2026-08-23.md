# Benchmark results - 2026-08-23

Ran on my desktop computer with an AMD Ryzen 7 7700X on Linux x86-64 usingRust
1.97.1 from my devshell. Criterion ran on CPU 2 with a 1 second warm-up, 2
second measurement window, and 20 samples. Values below are the estimated means
from one uninterrupted run. You might get slightly different results on
different hardware but the trends should remain the same.

## Peak heap while parsing `large`

Massif 3.27.1 measured one parse in each isolated adapter. Input generation is
included but file I/O isn't.

| Adapter | Peak heap bytes |
| ------- | --------------: |
| Nixon   |       2,710,549 |
| rnix    |       4,262,041 |
| NixEL   |      14,675,107 |

Nixon's retained syntax record is 15 bytes per node or token. Parser events and
tree records are allocated in fixed chunks, allowing completed event chunks to
be released while the output is built.
